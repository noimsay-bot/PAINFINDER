# 점수 가중치 자동 학습 — 보류

점수 가중치를 사용자 판정으로 자동 조정하는 기능은 현재 구현하지 않는다.

시장 판정 임계값과 최종 룰 필터를 2026-07-23에 교정했으므로, 먼저 새 기준으로 판정 데이터가 최소 수백 건 쌓여야 한다. 기각에는 실제 품질 문제뿐 아니라 익숙하지 않은 분야나 검토 피로 같은 사용자 편향도 섞일 수 있어, 이를 바로 점수에 반영하면 탐색 범위를 스스로 좁힐 위험이 있다.

현재 학습 범위는 다음으로 제한한다.

- 기각 사유를 구조화해 저장한다.
- `페인포인트 아님`에서 제외 키워드 후보를 만든다.
- `관심 밖 분야`에서 제외 도메인 후보를 만든다.
- 같은 제안이 2회 이상 발견돼도 자동 적용하지 않고 사용자가 승인해야 룰에 추가한다.
- `추적` 후보의 도메인·시장 판정·점수대는 통계로만 보여준다.

향후 점수 학습을 검토할 조건:

1. 교정된 점수 기준의 판정 데이터가 최소 수백 건 누적될 것
2. 승인형 룰 강화 적용 전후의 오탐률 변화가 확인될 것
3. origin별 표본 편향과 관심 분야 편향을 별도로 검토할 것
4. 자동 반영이 아니라 오프라인 재평가와 사용자 승인 절차부터 설계할 것
